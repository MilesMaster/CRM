# Lumière Kunden · Übergabeblatt

**Was die App ist:** eine Kundenkartei, die nur auf diesem iPad lebt. Es gibt
keinen Server und kein Konto. Die Daten verlassen das iPad nur, wenn Sie selbst
eine Sicherung exportieren.

## 1. Installation (einmalig)

1. iPad mit iPadOS 16.4 oder neuer.
2. In **Safari** die Adresse der App öffnen (siehe unten).
3. Oben auf **Teilen** tippen (Viereck mit Pfeil), dann **Zum Home-Bildschirm**,
   dann **Hinzufügen**.
4. Ab jetzt immer über das Symbol **Kunden** auf dem Home-Bildschirm starten,
   nicht über Safari. Nur so bleiben die Daten dauerhaft gespeichert.

Adresse: **https://milesmaster.github.io/CRM/**

## 2. Gerätecode (Pflicht)

Das iPad muss mit einem Gerätecode geschützt sein (Einstellungen › Face ID/Touch
ID & Code). Die App hat kein eigenes Passwort.

## 3. Sicherung (monatlich)

- In der App **Sicherung › Sicherung exportieren (JSON)** tippen und
  **In «Dateien» sichern** wählen, am besten in iCloud Drive.
- Die App erinnert, wenn die letzte Sicherung älter als 30 Tage ist.
- Zusätzlich iCloud-Backup des iPads einschalten (Einstellungen › Ihr Name ›
  iCloud › iCloud-Backup).
- **Achtung:** Wird das Symbol vom Home-Bildschirm gelöscht, sind die Daten weg.
  Dann App neu hinzufügen und unter **Sicherung › Sicherung auswählen** die
  letzte JSON-Datei einlesen.

## 4. Kalender

- Oben auf **Kalender** tippen. **Woche** oder **Monat** wählen, mit **‹ ›**
  blättern, **Heute** springt zurück.
- Neuer Termin: in der Woche beim Tag auf **+** tippen, Kunde suchen und
  antippen (oder **+ Neuer Kunde**), Uhrzeit und Leistung eintragen,
  **Speichern**. Oder in der Kundenkarte **+ Neuer Termin**.
- Termin antippen: ändern oder löschen.
- Die Termine sind nur auf diesem iPad. Die App erinnert nicht von selbst an
  Termine.
